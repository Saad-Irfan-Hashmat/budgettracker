# Budget Tracker
A simple and intuitive budget tracker to manage your income, expenses, and savings in one place. Track your spending, set budgets, and monitor your financial goals with ease. Get clear insights into your finances and make smarter money decisions every day.


A Windows Forms Budget Tracker developed in C#.
Features:

User Registration

User Login

Add Expenses

View Expenses

Update Expenses

Delete Expenses

Calculate Total Expenses   OOP Concepts:

Encapsulation (Expense class)

Abstraction (Transaction class)

Inheritance (ExpenseTransaction class)

Polymorphism (Override GetAmount())   Database:

SQL Server LocalDB

expense.mdf


#How to Run:

Open Debug folder

Run Budgettracker.exe
